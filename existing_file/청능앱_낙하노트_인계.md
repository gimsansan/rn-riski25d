# 청능앱 — 낙하노트 훈련모드 작업 인계문

> 이 문서는 확정된 결정을 다음 세션으로 넘기기 위한 것. 아래 결론은 **재검토 전까지 구속력 있는 기준**으로 취급.

---

## 1. 목적·전제 (가장 중요 — 여기서 모든 판단이 갈림)

- **청능(청각) 개선·치료 목적** 앱. 리듬게임 재미는 수단이지 목적 아님.
- **전 연령 타겟**(아동·성인·고령), **저난이도 지향**.
- 목적의 정체 = **넓은 청각 노출·친숙화 + 상대음감 노출·강화**. "절대 식별 극대화"가 목적이 **아님**.
- 학습 구조 = **다감각(시각+청각+운동)**. 화면의 "높은 음 = 위" 매핑이 핵심 장치.

---

## 2. 핵심 설계 원칙 (standing 결론 — 흔들지 말 것)

- 낙하노트 다감각 설계는 **연습·친숙화에 좋다**. 단, **시각이 답을 100% 고정으로 다 주면 청각 개선이 약해진다**(시각 우세, visual dominance).
- 그래서 전체 그림은 **"시각 힌트 제거 스펙트럼"**: `완전 힌트 → 부분 힌트 → 최소 힌트 → 청각 단독`. 왼쪽=연습(시각 주도), 오른쪽=식별(청각 주도).
- 이 스펙트럼이 곧 **치료 커리큘럼**. 시간이 갈수록 시각 부하↓·청각 부하↑.

### 원칙 vs 실제 (항상 같은 자리에 명시)
- **원칙**: 청각 개선을 위해선 의미 있는 청각 부하 상승이 이상적.
- **실제 권장**: 전연령·저난이도 노출앱이므로 **난이도는 낮게 유지**. 청각 부하는 **옅게/선택으로만**. 앱 대부분이 쉬운(스캐폴드) 쪽에 머물러도 OK.
- 둘은 모순 아님 — 목적이 "청각 극대화"가 아니라 "넓은 노출·친숙화"라 후자를 택하는 것.

---

## 3. 두 모드 (확정)

### 맛보기(연습)모드
- **입문/초급**, 백건만, **고정 뷰포트**, **시각 힌트 강함**(정답 레인/건반 강조).
- 여기서 **점진적 진행 없음**(고정 입구). 일 = "오류 없이 성공하며 익숙해지기".

### 훈련모드
- **진행(난이도↑)은 여기서만.** 통과 시 난이도 상승.
- 음계 선택지 **두 갈래**: **5음(펜타토닉)** / **8음(백건 1옥타브)**. 각 선택지 안에서 곡이 성립.
- 난이도 상승은 **청각 부하 축 우선**(순서): ① 정답키 강조 끄기 → ② 낙하 노트 흐리게/제거 → ③ 소리 먼저 들려주기 → ④ 음정 좁히기(옥타브→반음).
  - 속도↑·동시 노트↑ 는 **반응/운동 부하지 청각 부하가 아님** → "양념"으로만.
- **중급 이상(흑건=반음 변별, 상급 옥타브 시프트)은 맛보기에 넣지 않음.** 훈련 진행 몫.

## 4. 낙하노트 사양 (확정)

- **한 음씩** 순차 하강(동시 낙하 없음, 있어도 **최대 2개**).
- **저속**(빠를 필요 없음). bpm 72 기준.
- **수수한 톤**. 초기 참고 스샷(Magic Tiles/Piano Tiles류 화려함)은 목표 아님. 기준 톤 = 우리 목업(노트 몇 개 + 판정선 + 색 구분).
- **"귀 먼저" 선택 토글**: 정보 순서를 뒤집는 옵션(소리를 반박자 먼저 → 시각은 확인용). **기본 OFF, 원하는 사람만 ON**. 동기부여(선택형 도전 배지)와 결합 가능. 난이도 상승 아님.
- 채점: 판정선 도달 타이밍 대조. (옵션) 타이밍 정확도 차등 점수, O/X는 "얼마나 틀렸는지"의 시각화로 발전.

## 5. 곡·음원 (확정, 데이터는 `data/songs.ts`에 구현됨)

- 곡 = **음+타이밍 데이터**(개별 샘플 재배열). 총 4곡:
  - 자작 펜타토닉 2곡(5음: `C4·D4·E4·G4·A4`) — 저작권 클린.
  - 국제 PD 2곡(8음: 백건 `C4~C5`) — 반짝반짝 작은별, 메리의 어린 양.
- 음원: 개별 음 샘플 52개 재사용(**m4a → wav 교체 가능**). 우리가 배열하므로 **녹음 저작권 없음**.
- **성능**: 곡 개수·음원 포맷은 성능 **무관**. 유일 변수 = **동시 낙하 노트 수**(1~2로 고정 → 사실상 무의미). 입자는 이미 120개 상한.
